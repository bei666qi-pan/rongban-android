# 绒伴首版验收报告

罗森 · 202405100233 · 2026-10-13

## 环境与范围

主要设备为 Android 15 ARM64 模拟器，按约 2GB 内存环境验收，界面为 720 × 1600。APK 包含 ARM64 与 x86_64 语音运行时和离线模型。没有把模拟器结果当作真实手机性能、多人识别准确率或参与者可用性研究。

## 自动化验证

14 项核心 JVM 测试覆盖中文时长、缺参补全、普通聊天不误启动专注、记忆筛选与排序、CSV 转义、技能格式、三种协议、流式响应、鉴权失败、取消、超时，以及慢消费者接收全部 300 个文字片段。

8 项设备测试覆盖中文 TTS 有效音频、人声 ASR 预期关键句、原生资源初始化、数据库重开、PNG 长文分页完整性、记忆界面、记忆修改与停用、重复候选、技能导入规则和禁用执行器。新增进程中断后的回复恢复，以及停止后立即重新发送的请求隔离回归。

人声样本保持上游原文件，来源与校验在 third_party/asr-reference.json。预期关键句是“对我的研究感兴趣”。不把合成音频回识别当成人声准确率统计。

## 真实接口

MiMo 真正返回过 HTTP 200。设备界面先保存饮茶和猫咪偏好，另开会话获得引用这两项的回复，并生成卡片、进入系统分享面板。使用故意错误的 Key 请求实际服务，返回 HTTP 401。其他协议、超时和取消的异常路径采用受控响应；不声称完成了 Anthropic 或 Gemini 账号联调。

## 文件与界面证据

系统文件保存流程已生成真实 PNG 和五页 ZIP；读取实际 ZIP 后验证 CRC 完整、包含五张 1080 × 1440 PNG。卡片支持页码切换、单页 PNG、多页 ZIP 和多图片分享。主 App 演示为 177 秒，卡片演示为约 180 秒。主录屏以文字发起本地指令，并调用本地 TTS；ASR 单独使用原样人声样本验证，未把文字输入录屏当作麦克风识别证据。两段演示使用真实模拟器操作与系统屏幕录制，无旁白；主 App 删除了空白启动等待，并拼接真实桌面桌宠片段。系统弹窗中的水印由录屏后处理补充，姓名学号来自设备设置。

源码中的演示脚本默认跳过 CI，需要显式 demo 参数才执行。录屏不把失败片段、静态原型或模拟接口回复当作实际功能展示。

## 手工补充验收

Android 桌面跨应用显示桌宠已确认，拖动后的位置写入本地偏好。持续前台通知存在；暂停后通知标题变为“绒伴正在休息”，关闭后服务与通知消失。悬浮权限拒绝时跳转系统设置并提示如何返回开启，主界面的记忆仍可使用。麦克风拒绝后保留对话文字输入。通知权限拒绝时，主 App 可继续使用。

通过系统文件选择器导入 examples/gentle-study/SKILL.md 后，技能列表显示“温柔复习教练”；非法格式与禁用行为由逻辑及设备测试覆盖。

CSV 保存期间旋转到横屏再回到竖屏，系统保存完成后产生 175 字节真实 CSV，包含 UTF-8 BOM、表头和所选的饮茶／猫咪记忆。并非只验证点击按钮；已读取文件并检查内容。

长时间运行后模拟器进程曾退出；重启时 Android System UI 曾报告无响应，之后可恢复使用。这是本次环境中观测到的系统问题，没有足够证据归因于 App；未据此宣称长时间稳定性通过。

## 修复记录

- 统一原生识别资源路径，修复 AssetManager 与绝对热词路径混用造成的进程退出。
- 增加语音准备状态，识别结果可校正后发送，避免误字立即触发操作。
- 对取消的请求绑定独立回复 ID 与版本，旧请求不能修改新回复。
- 进程恢复时标记未完成回复为已中断，提供重试。
- 自动生成的事实和情境摘要都需确认，编辑、停用和遗忘会清理旧摘要，并取消相应整理任务。
- 保存文件时保留待导出的文件路径，CSV 选择与内容保留可恢复状态。
- CI 运行 App 的测试入口，覆盖共享库与卡片，避免启动空的库测试安装包。
- 本机调试接口绕过设备代理，调试网络仅为准确匹配的本机地址允许明文。

## 限制

语音可能有误字，首次初始化需要数秒；应在“正在听”出现后说话，并检查结果。专注后台通知可能受系统节电策略延迟。尚未完成物理手机、不同说话者和长时间连续使用的性能研究。

最终 Gradle、设备测试、接口测试输出与截图随交付材料保留。CI 状态以各 PR 当前提交的 GitHub 检查为准。
