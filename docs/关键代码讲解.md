# 关键代码讲解与答辩准备

罗森 · 202405100233

1. 为什么使用原生 Android？课程要求 Kotlin / Java 原生；Compose 负责界面，Android API 负责设备与系统入口。
2. C3 的自定义业务逻辑在哪里？CommandParser 实现同义指令、中文数字时长、缺参追问和范围检查；MemoryContext 实现记忆筛选、评分与上下文预算。
3. 断网还能做什么？录音识别、本地 TTS、记忆存取、专注、卡片绘制、PNG/CSV 保存与系统分享都在本地完成；自由聊天和 AI 总结需要服务连接。
4. 为什么 Room 配合 DataStore？Room 管理有关系且可查询的业务数据；DataStore 管理少量配置。API Key 单独经 Keystore 加密。
5. 如何避免主线程阻塞？网络事件通过 Flow，数据库使用 suspend DAO，语音和位图工作在后台协程执行；页面通过生命周期相关的状态订阅更新。
6. 如何处理录音生命周期？停止时通知采集循环退出，在 finally 释放录音对象、识别流和模型；页面切后台会停止语音资源。
7. “记忆”是否是完整聊天记录？聊天记录是原始历史；记忆是明确保存或确认的事实，情境摘要是受限的近期概括。三者分别处理。
8. 为什么模型提取需要确认？模型可能误解或推断，候选记忆让用户控制持久保存的内容。
9. 删除记忆后为什么还保留对话？二者是独立数据。删除记忆停止之后的跨会话引用，删除原始对话需要另一个明确操作。
10. Skill 是否能自动操作手机？提示技能只影响回复方式。手机动作由有明确参数的内置执行器处理，没有自主工具循环。
11. 怎样切换供应商？配置协议、Base URL、模型名与 API Key；统一适配器处理不同请求和流式文字格式。
12. P4 为什么能独立验收？同一 APK 提供第二个桌面入口，卡片 Activity 独立读取共享数据库并完成编辑、预览、导出和分享。
13. 为什么用 FileProvider？向其他 App 提供受限 content URI，结合临时读取权限，避免暴露应用私有文件路径。
14. 长文如何分页？StaticLayout 计算实际行高，按照页内可用高度划分连续文本范围。测试验证所有分页拼接回原文。
15. Git 记录能说明什么？每个功能、修复与测试有真实提交和 PR；不能把同日开发记录包装成两个月的课程过程。

复习时应自行定位这些类，能解释实际参数、失败处理和资源释放路径。不要只背这份讲解。
